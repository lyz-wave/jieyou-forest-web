# 第三阶段：沉淀与年轮（stage3-rings）

## Why

产品文档第六节的结束流程（「🌱 心结解开了」→ 再次打分 → AI 沉淀 → 年轮生长 → 成长卡片）和 6.4 的年轮三级浏览，是「沉淀成长」这条主线的落点：现在的倾诉走完就没了，古树上「🌳 我的年轮」只给一句「年轮还在生长」。第三阶段把这条线接通——数据落到本机 IndexedDB，年轮长出第一圈。

## What Changes

1. **数据层**（`lib/db/`）：Dexie 升到第 2 版，加入 `sessions`（`id, startedAt, status`）与 `memories`（`id, date, sessionId`）两张表，并写迁移测试（第 1 版的资料行必须活着）。类型按文档第九节：`Message` / `Session` / `Memory`；`themes` 只能取自固定标签库（工作压力 / 职场人际 / 亲密关系 / 家庭 / 友情 / 自我价值 / 学业考试 / 健康 / 金钱 / 未来迷茫 / 失去与离别 / 孤独 / 其他）。
2. **年轮的纯函数**（`lib/rings/`）：按年 / 月 / 日分组、圈宽（设上下限）、当年主导情绪配色、主题筛选高亮、面包屑文案、演示数据（带种子、跨 2–3 年）。全部先写测试。
3. **沉淀**（`lib/journal/`）：结束页再次打分（可跳过）→ `POST /api/memory`（Prompt 见文档 10.4，轻量模型）→ 写 `Memory` + 把 `Session` 标成 `resolved` → 年轮生长动画（光点从树干外缘长成一圈）→ 成长卡片。`helpfulAnimals` 来自用户点过「说到心里了」的动物（`resonated` 的那几条发言，只能是七只动物的发言）。
4. **先放一放**：`Session.status = "paused"` 存下来；下次进森林时古树轻声问「上次那件事，还想接着聊吗？」，可以接着聊。
5. **年轮页**：年层 → 月层（12 圈，没记录的月份是浅色细线）→ 日层（只显示有记录的日子）三级浏览，顶部面包屑「全部 › 2026 › 3月 › 12日」，支持手势缩放与返回、按主题筛选高亮、成长卡片列表（对话原文默认折叠）、空状态「你的第一圈年轮，正在生长」。
6. **开发模式**：`?dev=1` 下提供「生成演示数据」按钮，生成跨 2–3 年的假记录，用来看年轮效果。

## 不在这一阶段

- 记忆唤醒（第七节）、数据导出/导入/删除/清空（第九节的设置页）、音效与动画打磨 → 第四阶段（HANDOFF 11.3）。
- 倾诉的语音输入（文档 6.3.3 的可选项）：用户 2026-10-08 说「语音输入可以以后完成」。

## Capabilities

- 新增：`ring-browser`（年轮三级浏览与成长卡片）、`growth-sedimentation`（沉淀与新会话状态）。
- 影响：`lib/stores/talk.ts`（结束时回报分数与发言）、`components/talk/*`（结束页）、`components/forest/*`（古树入口与追问）、`lib/db/profile.ts`（与新的 db 模块共用 Dexie 实例）。

## Impact

- 用户的倾诉原文与成长记忆从这一刻起落在本机 IndexedDB（之前只在内存里，关掉页就没了）。首次写入前要在界面上说清楚：数据只在这台设备上。
- 断开 AI 时结束流程仍要能走完（降级成手动填一张卡片，或先存 `paused`）。
