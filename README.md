# 解忧森林

一个 2.5D 剪纸风的治愈系 Web 应用：森林里的动物陪你释放情绪、换个角度想问题，再把成长沉淀进古树的年轮。

> 解忧森林不能替代专业心理咨询。

线上地址：<https://jieyou-forest-web.radiant-hawking.workers.dev>（Cloudflare Workers；部署与再发布见文末「部署」）。

## 当前进度：第三阶段进行中（沉淀与年轮已经能走通）

**倾诉与圆桌（第二阶段）**：点「开始倾诉」，七只动物聚到古树前坐好，界面就开始了：

1. **心情打分**（1–10，可以跳过）→ **写下想说的话**（最多 1000 字，输入框下面写着这段话去哪儿）
2. **聆听**：森林安静下来，飘着的纸屑停住，动物们轻轻点头、竖起耳朵，团团会托腮（跟随系统的「减弱动画」偏好，减弱时是静止一幕）
3. **风险守护**：每句话都先用本机词表粗筛一遍，认得出危险词就当场停下、不再外发；其余交给服务端用一个轻量模型再判一次，分三档——**none** 继续；**concern**（很沉、需要有人陪着，但还没到危险）照常圆桌，只在古树的总结里温和地提一句值得找专业的人聊聊；**crisis**（自杀、自伤、伤害他人，或正在遭受暴力）立刻停下：动物安静下来、不做圆桌发言，岁岁先用认真温和的语气回应，给出三条出路与求助卡（全国心理援助热线 12356、希望 24 热线 400-161-9995、紧急情况 110 / 120，**上线前必须再核实一次**），勾上「我现在是安全的」才能继续
4. **圆桌**：伙伴先说，其余按顺序。正在说的那只走到古树前方、微微放大，头顶气泡一个字一个字地出，下面标着它的思维方式；说完回到自己的位置。可以「下一位」，也可以「全部显示」，每段还能点「说到心里了」；没在说话的那几只也在点头、偏头想、轻轻笑
5. **古树总结**：岁岁发光，说五段——我听到了 / 森林的声音（并标明这话来自谁）/ 一个可以带走的念头 / 一个小小下一步 / 一个开放式的问题
6. **追问**：默认问岁岁；点头像或者写 `@墨墨` 都能指名某一只；也可以「让大家再说说」（再请一轮时会把已经说过的带给它们，免得复读）
7. **收尾**：「心结解开了」→ 再打一次分（可以跳过）→ 岁岁把这一次沉淀下来 → 年轮长出新的一圈 → 拿到这次的**成长卡片**；或者「先放一放」，把这一次原样留在本机（标记成暂停），下次进森林时会看到岁岁轻轻问一句「上次那件事，还想接着聊吗？」

**入林引导**：五步纸艺引导（走进森林 → 认识岁岁 → 取昵称 → 了解规则 → 选今天的伙伴），最后一步才写入本机，刷新后直接回到森林。
最后一步如果拿不定主意，可以点「不知道找谁？帮我看看」：答三句「此刻想被怎么对待」，森林推荐一位并说清为什么，你可以接受，也可以回到卡片自己挑。它只看你当下的需要，不做人格测验、不贴标签，也不把这件事告诉任何人；本机只记一条 `{ 时间, 当时的说法, 选了谁, 是自己挑的还是推荐的 }`。

**2.5D 剪纸森林**：三层层叠的纸雕远景、纸纹与毛边、飘落的叶子，相机跟着鼠标（手机上跟着重力感应）轻微移动；光线按真实时间在清晨／白天／黄昏／夜晚之间变化。

**七只动物，七种看问题的方式**。每只动物都有一张角色卡，写着物种、思维方式、心理学依据和一句样句，点开就能跟它玩一个小游戏：

| 动物 | 思维方式 | 心理学依据 | 小游戏 |
| --- | --- | --- | --- |
| 笃笃（啄木鸟） | 情绪觉察 | 情绪标注 | **敲树洞**：敲几下，从飘出的词卡里挑出此刻的情绪 |
| 墨墨（猫头鹰） | 理性分析 | 认知行为疗法 | **事实还是猜测**：把困扰的话拆进两个树洞，认出思维陷阱 |
| 阿橘（狐狸） | 换个角度 | 认知重构 | **翻面镜**：把想法翻个面，收藏让你笑出来的说法 |
| 团团（熊） | 自我关怀 | Self-compassion | **熊抱**：长按抱住团团，听它慢慢说 |
| 慢慢（乌龟） | 时间视角 | 10-10-10 法则 + 正念 | **龟壳呼吸**：跟着壳上的方框做 4-4-4-4 呼吸 |
| 漂漂（水獭） | 放下与解离 | ACT 认知解离 | **落叶漂流**：把念头写到叶子上放走（不记录、不保存） |
| 跳跳（松鼠） | 行动派 | 问题解决／行为激活 | **藏坚果**：把一件事拆成今天就能做的三个小步 |

**年轮与成长卡片（第三阶段）**：倾诉收尾、打完第二次分，这一次会沉淀进古树的年轮。

- **成长卡片**上写着：日期与标题、心情变化（4 → 7）、「从『…』到『…』」的思维转变、一句领悟、一个小行动，以及这次帮到你的动物头像。模型只负责卡片上的字；「帮助最大的动物」来自你在圆桌上点过「说到心里了」的那几只。
- **年轮页**从古树的角色卡点进去，是一截**剪纸锯下来的木头**：外面一圈是剪出 13 瓣花边的树皮，里面是浅色的木头切面（一根木纹、一块不规则的「胚」）；每一圈年轮都是一张手剪的环形纸片——宽窄沿圆周不匀、纸边还剪着小镂口，从外到内一层层垫高，纸下留着裁口的厚度和影子。分三级：年层（一圈一年，圈宽按那年记录数、颜色由那年主导的情绪色调混合，每圈纸边下写着年份）→ 点进去是 12 圈月轮（有记录的月份是一圈纸，纸边缀一颗光点；没记录的月份只是浅色细线）→ 再点进去是有记录的日子 → 当天的成长卡片列表。点某一圈时，那一圈会先抬起来发光，再展开成下一级。面包屑「全部 › 2026 › 3月 › 12日」逐级返回；也可以**双指张开／捏合**进出下一层（桌面上按住 Command 滚一格），或**向右划**返回上一层；按主题筛选时，只有相关的圈会亮起来。还没记录过的时候，年轮上只有一句「你的第一圈年轮，正在生长」。
- **存在哪**：只存在这台设备上（IndexedDB，Dexie 升到第 2 版，三张表 profile / sessions / memories，旧版资料会自动保留）。没有账号、没有上传；导出、导入、删除留到第四阶段。
- **对话原文**也在这台设备上（跟着那一次会话一起存），卡片里默认折着，点开「那天的对话」才展开。

**森林里的互动**：点古树岁岁进年轮（第三阶段已开放，见上）；玩过的小游戏会让刚陪你玩的那只动物轻轻跳一下；点「开始倾诉」就进入上面那段流程。

**小游戏留下的上下文**：玩过的游戏会把结果记在内存里（最多 20 条，关掉页面就没了），倾诉时会当成背景交给模型——所以古树能提一句你刚才在敲树洞时写下的情绪。

**AI 走服务端接口**：`app/api/` 下八个 Route Handler——倾诉四个（`roundtable` / `summary` / `reply` / `risk`）、沉淀一个（`memory`）、小游戏三个（`split-thought` / `reframe` / `break-down`）。模型回复一律按严格 JSON 校验（手写守卫，缺字段、类型不对、多余字段都算不合格），Prompt 集中在 `lib/prompts.ts`；前端只有一个入口 `getForestAI()`，小游戏代码一行没改。第一阶段的本地模拟（`lib/ai/mock.ts`）留作离线参考。

**无障碍与体感**：跟随系统的「减弱动画」偏好（也可以在森林里手动关掉视差与粒子）；所有可点区域不小于 44×44 像素；拖拽都留了「点一下选中 → 点目标放下」和「Tab + 回车」两条替代路径。界面里没有 emoji：动物的标记是缩小版真纸偶（和森林里那只是同一套纸片），叶子、羽毛是纸片图形，读屏只会读到文字。

## 环境要求

- Node.js 22+
- npm 10+

## 安装

```bash
npm install
npx playwright install chromium   # 只在需要跑 E2E 测试时
```

## 配置模型（倾诉与三个 AI 小游戏要用）

```bash
cp .env.example .env.local
```

然后填上：

```bash
ANTHROPIC_API_KEY=sk-ant-...
JIEYOU_MODEL_MAIN=claude-sonnet-5              # 圆桌发言、古树总结、追问、小游戏
JIEYOU_MODEL_LIGHT=claude-haiku-4-5-20251001   # 风险检测
```

**没有 Key 也能跑**：入林、森林、敲树洞、熊抱、龟壳呼吸、落叶漂流、藏坚果的非 AI 部分都照常；涉及模型的几处会显示同一句「风太大了没听清，能再说一次吗？」和「再试一次」——这里不假装有回应，也不偷偷改用第一阶段的本地模拟。

> 两个模型名抄自产品需求文档，**上线前要用当时可用的模型 ID 核实一遍**（改环境变量即可，不用动代码）。服务端不打印用户写的内容。

部署到 Cloudflare 时用同名的三个变量（`npx wrangler secret put`），见「部署」一节。

## 运行

```bash
npm run dev
```

- 打开 <http://localhost:3000> 进入森林
- 打开 <http://localhost:3000/style-sample> 查看风格样板页（仅开发模式）

手机预览：手机和电脑连同一个 Wi-Fi，用 `npm run dev -- -H 0.0.0.0` 启动，然后在手机上访问 `http://<电脑的局域网 IP>:3000`。

## 部署（Cloudflare Workers）

线上跑在 Cloudflare Workers 上：<https://jieyou-forest-web.radiant-hawking.workers.dev>（Worker 名 `jieyou-forest-web`，用 Cloudflare 官方的 `@opennextjs/cloudflare` 适配器把 `next build` 的产物适配到 workerd）。

```bash
npm run preview   # 本地按生产的样子跑一遍：先构建，再用 wrangler dev 起在 http://localhost:8787
npm run deploy    # 构建并发布到 Cloudflare
```

- **三个变量**：`ANTHROPIC_API_KEY`（不设的话八个接口都回 503，界面走「风太大了没听清」那句降级话）、`JIEYOU_MODEL_MAIN`、`JIEYOU_MODEL_LIGHT`（后两个可选）。线上用 `npx wrangler secret put ANTHROPIC_API_KEY` 设置；本地预览把 `.dev.vars.example` 复制成 `.dev.vars`（已在 `.gitignore` 里）。
- **日常开发不受影响**：还是 `npm run dev`，单测和 E2E 也照旧。`next.config.ts` 里**没有**加 `initOpenNextCloudflareForDev()`——这个项目不用 Workers 的绑定，没必要让开发服务器多启一个 workerd。
- **数据仍然只在这台设备上**：IndexedDB 按域名分家，`localhost` 上长出来的年轮不会跟着到线上地址，线上地址的年轮也不会回到本地。
- 部署体积 gzip 约 1.1 MB（免费版上限 3 MB）；首页是静态资源，Worker 只在访问 `/api/*` 时运行。
- **接口有一道最基础的限流**：同一个 IP 一分钟最多 20 次（`lib/ai/limit.ts`），超了回 429 + `Retry-After`，界面和其它失败一样走「风太大了没听清」那句。计数器在 Worker 进程内存里、不跨机房，挡的是手滑连点和一台机器的滥用；真正的花费上限还是去 Anthropic 后台设一个月度额度。

## 开发提示

- 开发模式加 `?dev=1` 会出现右下角调试抽屉：看 `gameContext`、模拟 AI 失败、切换时段，以及一个**「生成演示数据」**按钮（往年轮里写一批跨 2–3 年的假记录，固定种子、同种子同结果）。
- `/style-sample` 风格样板页只在开发模式存在，生产构建访问会 404。
- 截图自检的产物在 `docs/`：`docs/onboarding/`（入林五步与引导选伙伴）、`docs/forest/`（森林主场景与调试抽屉）、`docs/games/`（七个小游戏）、`docs/talk/`（打分、圆桌、古树总结、危机守护页）、`docs/rings/`（成长卡片、年轮的年层／月层／日层、空状态与演示数据）。跑一遍 E2E 就会重新生成。
- 如果本机开着一个 `npm run dev`，`npm run test:e2e` 会因为 Next 16「同一目录只允许一个 dev server」起不来；这时改用 `npx playwright test --config=playwright.existing-dev.config.ts <测试文件>` 复用已经在跑的那个（默认 3200，可用 `DEV_URL` 覆盖）。
