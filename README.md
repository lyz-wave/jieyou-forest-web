# 解忧森林

一个 2.5D 剪纸风的治愈系 Web 应用：森林里的动物陪你释放情绪、换个角度想问题，再把成长沉淀进古树的年轮。

> 解忧森林不能替代专业心理咨询。

## 当前进度：第一阶段已完成（可验收）

**入林引导**：五步纸艺引导（走进森林 → 认识岁岁 → 取昵称 → 了解规则 → 选今天的伙伴），最后一步才写入本机，刷新后直接回到森林。

**2.5D 剪纸森林**：三层层叠的纸雕远景、纸纹与毛边、飘落的叶子，相机跟着鼠标（手机上跟着重力感应）轻微移动；光线按真实时间在清晨／白天／黄昏／夜晚之间变化。

**七只动物，七种看问题的方式**。每只动物都有一张角色卡，写着物种、思维方式、心理学依据和一句样句，点开就能跟它玩一个小游戏：

| 动物 | 思维方式 | 心理学依据 | 小游戏 |
| --- | --- | --- | --- |
| 笃笃（啄木鸟） | 情绪觉察 | 情绪标注 | **敲树洞**：敲几下，从飘出的词卡里挑出此刻的情绪 |
| 墨墨（猫头鹰） | 理性分析 | 认知行为疗法 | **事实还是猜测**：把困扰的话拆进两个树洞，认出思维陷阱 |
| 阿橘（狐狸） | 换个角度 | 认知重构 | **翻面镜**：把想法翻个面，收藏让你笑出来的说法 |
| 团团（熊） | 自我关怀 | Self-compassion | **熊抱**：长按抱住团团，听它慢慢说 |
| 慢慢（乌龟） | 时间视角 | 10-10-10 法则 + 正念 | **龟壳呼吸**：跟着壳上的方框做 4-4-4-4 呼吸 |
| 漂漂（水獭） | 放下与解离 | ACT 认知解离 | **落叶漂流**：把念头写到叶子上放走（不记录、不保存） |
| 跳跳（松鼠） | 行动派 | 问题解决／行为激活 | **藏坚果**：把一件事拆成今天就能做的三个小步 |

**森林里的互动**：点「开始倾诉」让动物们聚拢过来、安静听你说（第二阶段的入口）；点古树岁岁看年轮（第二阶段开放，现在只给一句提示：年轮还在生长）；玩过的小游戏会让刚陪你玩的那只动物轻轻跳一下。

**小游戏留下的上下文**：玩过的游戏会把结果记在内存里（最多 20 条，关掉页面就没了），第二阶段倾诉时给 AI 当背景。

**AI 目前是模拟数据**：第一阶段不调用任何外部服务，气泡、拆解、重构都由 `lib/ai/mock.ts` 生成——同样的输入给同样的结果，整条流程离线也能走一遍。

**无障碍与体感**：跟随系统的「减弱动画」偏好（也可以在森林里手动关掉视差与粒子）；所有可点区域不小于 44×44 像素；拖拽都留了「点一下选中 → 点目标放下」和「Tab + 回车」两条替代路径。界面里没有 emoji：动物的标记是缩小版真纸偶（和森林里那只是同一套纸片），叶子、羽毛是纸片图形，读屏只会读到文字。

## 环境要求

- Node.js 22+
- npm 10+

## 安装

```bash
npm install
npx playwright install chromium   # 只在需要跑 E2E 测试时
```

第一阶段不调用任何外部服务，**不需要 `.env`**。第二阶段接入 Claude API 后会补充配置说明。

## 运行

```bash
npm run dev
```

- 打开 <http://localhost:3000> 进入森林
- 打开 <http://localhost:3000/style-sample> 查看风格样板页（仅开发模式）

手机预览：手机和电脑连同一个 Wi-Fi，用 `npm run dev -- -H 0.0.0.0` 启动，然后在手机上访问 `http://<电脑的局域网 IP>:3000`。

## 测试

```bash
npm test            # 单元测试和组件测试
npm run test:e2e    # E2E 测试（会先执行生产构建）
npm run typecheck   # 类型检查
npm run lint        # 代码检查
```

- 单元／组件测试：52 个文件、371 个用例，覆盖缩放与热区几何、视差、拖拽落点、七个游戏的规则、AI 输入校验。
- E2E 用 Chromium 跑 375×667（手机）和 1440×900（桌面）两个视口：入林五步、森林布局与热区几何、七个小游戏走通一遍、画面底线（字体分片少于 30、做动画的元素不带 filter、减弱动画真的减）。

## 开发提示

- 开发模式加 `?dev=1` 会出现右下角调试抽屉：看 `gameContext`、模拟 AI 失败、切换时段。
- `/style-sample` 风格样板页只在开发模式存在，生产构建访问会 404。
- 截图自检的产物在 `docs/`：`docs/onboarding/`（入林五步）、`docs/forest/`（森林主场景与调试抽屉）、`docs/games/`（七个小游戏）。跑一遍 E2E 就会重新生成。
- 如果本机开着一个 `npm run dev`，`npm run test:e2e` 会因为 Next 16「同一目录只允许一个 dev server」起不来；这时改用 `npx playwright test --config=playwright.existing-dev.config.ts <测试文件>` 复用已经在跑的那个（默认 3200，可用 `DEV_URL` 覆盖）。
